## Python / PyInstaller / Tcl/Tk

패처는 Python 3.13과 PyInstaller 6.22.3으로 만들었습니다.
Python, PyInstaller 부트로더 예외, Tcl/Tk의 라이선스 전문을 이 폴더에 포함합니다.
패처 실행에 Python을 별도로 설치할 필요가 없습니다. 시스템의 맑은 고딕을 사용하며 글꼴 파일을 배포하지 않습니다.

## 게임 자료

령 / Fatal Frame / Zero와 게임 이미지의 권리는 원 권리자에게 있습니다.
배포 파일은 원본 일본판을 필요로 하는 차분 패치이며 게임 ISO나 완전한 원본 게임 파일을 포함하지 않습니다.
